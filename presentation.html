Smart Salary Calculator

מחשבון שכר חכם | Final Project Presentation

  • The Project: A full-stack web application for complex Israeli payroll calculations.
  • The Inspiration: The real-world difficulty of projecting net income.
  • The Goal: Bridge the gap between raw shift hours and actual take-home pay without needing an accounting degree.
"Hello everyone, I’m Eliyahu. For my final project, I’m excited to present the Smart Salary Calculator—a full-stack web application designed to take the headache out of Israeli payroll calculations. The inspiration for this came from a very real necessity. Most workers struggle to accurately project their net income because calculating daily shift variations, mandatory pension deductions, and tax points is incredibly complex. The problem I set out to solve was bridging the gap between a worker's raw hours and their actual take-home pay, without requiring an accounting degree."

The Solution & Target Audience

  • Target Audience: Hourly or shift-based workers in Israel.
  • User Experience: A responsive, highly visual 4-step guided wizard.
  • Key Differentiator: Dynamic daily shift matrix.
  • Automation: Automatically calculates 100%, 125%, and 150% overtime rates.
"The solution is a responsive, highly visual 4-step wizard that guides users smoothly through their data entry. My target audience includes any hourly or shift-based worker in Israel. What sets this apart from other calculators is the intuitive breakdown—especially the dynamic daily shift matrix that automatically calculates 125% and 150% overtime rates without the user having to do the math themselves."

Tech Stack & AI Integration

HTML5 CSS3 Vanilla JavaScript GitHub Netlify


  • State Management: Handled natively in the browser using JavaScript.
  • Hosting: Continuous deployment via Netlify (salarycalculator.work).
  • AI Tools Used: GitHub Copilot Pro & Claude.
  • AI Impact: Accelerated boilerplate, optimized tax bracket logic, and resolved CSS styling for print views.
"To build this, I used a frontend stack of HTML, CSS, and vanilla JavaScript to handle the complex state management and calculation logic natively in the browser. For version control, the entire codebase is managed in a dedicated GitHub repository. From there, I set up a continuous deployment pipeline using Netlify, hosting the live application securely on a custom domain at salarycalculator.work. Because this is our AI course finale, AI played a massive role in my workflow. I actively used AI development platforms like GitHub Copilot Pro and Claude to accelerate the boilerplate coding, optimize the JavaScript logic for the tax brackets, and troubleshoot CSS styling for the final print view."

Challenges & Testing

  • Architectural Challenge: Retaining state across steps.
  • Data Flow: Ensuring Base Salary (Step 2) carries flawlessly into Pension Deductions (Step 4).
  • QA Testing: Rigorous testing of the automated overtime transitions.
  • Edge Cases: Ensuring system behaves perfectly regardless of unexpected user inputs.
"Before the final deployment, I had to overcome a few significant architectural challenges. The most difficult part was state retention—ensuring that data entered in Step 2 for base salary carried over flawlessly to Step 4 for pension and study fund deductions. Extensive QA testing went into ensuring the automated transition of standard hours into overtime brackets behaved perfectly regardless of the inputs."

"Let’s jump into the live demo. (Click the link to open the site).

Here on the welcome screen, we keep it friendly and simple.
Moving to Step 1, the user enters their workplace and role.
In Step 2, we define the baseline: the month, hourly rate, and default tax points.
Step 3 is the engine of the app. As you can see, you just log your entry and exit times, and the system automatically categorizes the 100%, 125%, and 150% hours.
In Step 4, we calculate absences, travel expenses, and pension allocations.
Finally, the system generates a clean, visually distinct payslip that perfectly breaks down additions and deductions, giving us the final net pay, ready to be printed or saved."
