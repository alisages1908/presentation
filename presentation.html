מחשבון שכר חכם

מצגת פרויקט גמר

  • הפרויקט: אפליקציית רשת (Full-Stack) לחישובי שכר מורכבים בישראל.
  • ההשראה: הקושי האמיתי בחיזוי והערכת שכר הנטו.
  • המטרה: לגשר על הפער בין שעות המשמרת הגולמיות לשכר הנטו בפועל, ללא צורך בתואר בראיית חשבון.
"שלום לכולם, אני אליהו. בפרויקט הגמר שלי, אני נרגש להציג את 'מחשבון שכר חכם' - אפליקציית רשת שנועדה לחסוך את כאב הראש הכרוך בחישובי שכר בישראל. ההשראה לכך הגיעה מצורך אמיתי. רוב העובדים מתקשים לחזות במדויק את שכר הנטו שלהם מכיוון שחישוב שינויים במשמרות יומיות, הפרשות חובה לפנסיה ונקודות זיכוי מס הוא מסובך להפליא. הבעיה שרציתי לפתור הייתה גישור על הפער בין שעות העבודה הגולמיות של העובד לשכר שהוא לוקח הביתה בפועל, מבלי לדרוש תואר בראיית חשבון."

הפתרון וקהל היעד

  • קהל היעד: עובדים שעתיים או עובדי משמרות בישראל.
  • חווית משתמש: אשף רספונסיבי, ויזואלי ומודרך בעל 4 שלבים.
  • הייחוד: מטריצת משמרות יומית דינמית.
  • אוטומציה: חישוב אוטומטי של תעריפי שעות נוספות בשיעור של 100%, 125% ו-150%.
"הפתרון הוא אשף מודרך, רספונסיבי וויזואלי בעל 4 שלבים, המנחה את המשתמשים בצורה חלקה בתהליך הזנת הנתונים. קהל היעד שלי כולל כל עובד שעתי או עובד משמרות בישראל. מה שמייחד את המחשבון הזה ממחשבונים אחרים הוא הפירוט האינטואיטיבי - במיוחד מטריצת המשמרות היומית הדינמית המחשבת אוטומטית תעריפי שעות נוספות (125% ו-150%) מבלי שהמשתמש יצטרך לבצע את החישובים בעצמו."

טכנולוגיות ושילוב בינה מלאכותית

HTML5 CSS3 Vanilla JavaScript GitHub Netlify


  • ניהול מצב (State): מנוהל מקומית בדפדפן באמצעות JavaScript.
  • אחסון (Hosting): פריסה רציפה (CI/CD) דרך Netlify בכתובת salarycalculator.work.
  • כלי בינה מלאכותית: Google Gemini.
  • השפעת ה-AI: האצת כתיבת קוד בסיסי (Boilerplate), אופטימיזציה ללוגיקת מדרגות המס ופתרון באגים בעיצוב תצוגת הדפסה.
"כדי לבנות את זה, השתמשתי בטכנולוגיות צד לקוח של HTML, CSS ו-Vanilla JavaScript, במטרה לנהל את המצב המורכב ואת לוגיקת החישובים ישירות בדפדפן. לניהול גרסאות, כל הקוד מנוהל במאגר GitHub ייעודי. משם, הגדרתי תהליך פריסה אוטומטי באמצעות Netlify, והאפליקציה מאוחסנת בצורה מאובטחת תחת הדומיין salarycalculator.work. מכיוון שזהו פרויקט הגמר שלנו בקורס בינה מלאכותית, ל-AI היה תפקיד משמעותי בתהליך הפיתוח שלי. השתמשתי באופן פעיל ב-Google Gemini כדי להאיץ את כתיבת הקוד הבסיסי, לייעל את הלוגיקה של מדרגות המס ב-JavaScript ולפתור באגים בעיצוב ה-CSS עבור תצוגת ההדפסה הסופית."

אתגרים ובדיקות

  • אתגר ארכיטקטוני: שמירת נתונים (State) במעבר בין שלבים.
  • זרימת נתונים: הבטחה שנתוני שכר הבסיס (שלב 2) יעברו ללא תקלות לחישובי הניכויים לפנסיה (שלב 4).
  • בדיקות איכות (QA): בדיקות קפדניות של המעברים האוטומטיים בין מדרגות השעות הנוספות.
  • מקרי קצה: הבטחת התנהגות תקינה של המערכת גם במקרים של הזנות נתונים בלתי צפויות.
"לפני הפריסה הסופית, נאלצתי להתמודד עם מספר אתגרים ארכיטקטוניים משמעותיים. החלק הקשה ביותר היה שמירת המצב (State) - להבטיח שהנתונים שהוזנו בשלב 2 עבור שכר הבסיס יעברו ללא תקלות לשלב 4 לטובת חישוב הפקדות לפנסיה וקרן השתלמות. בנוסף, השקעתי זמן רב בבדיקות איכות (QA) כדי להבטיח שהמעבר האוטומטי משעות רגילות לשעות נוספות יעבוד בצורה מושלמת, ללא קשר לנתונים שהמשתמש מזין."
